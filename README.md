# netflix-data-analysis

This is a complete data analysis project that looks at Netflix's library. It figures out things like what kind of content is most popular, where movies and shows are being made, and how good their ratings are—using three main tools: Python, SQL, and Power BI.   

**The repository is structured into distinct folders to ensure a smooth workflow:**

1.the data/ directory houses the cleaned and processed dataset (netflix_cleaned.csv).

2.the sql/ directory contains a fully populated SQLite database (netflix.db) along with ready-to-run queries (analysis_queries.sql).

3.the python/ folder includes a script (eda_netflix.py) for exploratory data analysis and visual generation with Pandas and Seaborn.

4. the powerbi/ folder provides a step-by-step guide complete with KPIs and DAX measures for building an interactive executive dashboard.

**key insight**

Key insights drawn from the analysis reveal that movies comprise about 70 percent of the library while TV shows account for 30 percent, the United States and India lead global content production, and while action and drama genres drive high view counts, niche documentaries capture the highest critical IMDb ratings.
